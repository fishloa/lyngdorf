# MP-40 Oracle

Hardware lookup tables for the Lyngdorf MP-40 multichannel processor.

## Stream Types

**Source: firmware-verified** (disassembled `nsdkd` binary from `update-streaming_5.4.1.gpg`, function `getStreamtypeFromNsdkString` at 0x15840)

All MP series models (MP-40, MP-50, MP-60) share the same streaming firmware and identical stream type mapping.

| Index | Name | NSDK String |
|-------|------|-------------|
| 0 | None | *(default/no match)* |
| 1 | vTuner | VTuner |
| 2 | Spotify | spotify |
| 3 | AirPlay | airplay |
| 4 | UPnP | UPnP |
| 5 | Storage | Storage |
| 6 | Roon Ready | roon |
| 7 | TIDAL | tidal |
| 8 | airable | airableRadios, airablePodcasts |
| 9 | PureAudio | artistconnection |
| 10 | Qobuz | qobuzconnect |

### Notes

- Index 7 was previously "Unknown" in the library — firmware confirms it is TIDAL.
- Indices 8-10 (airable, PureAudio, Qobuz) were missing from the library.
- Both `airableRadios` and `airablePodcasts` NSDK strings map to the same index (8).
- The `artistconnection` NSDK string (PureAudio/AC connect) maps to index 9.
- No "bluetooth" or "GoogleCast" strings exist in the MP streaming firmware.
- vTuner functionality was removed in firmware 5.3.0 but the index still exists.

### Notes

- Gap at index 2: no "8 Channel Analog" on MP-40 (unlike P series).
- Gaps 13-23 and 25-34: unused.
- Unlike MP-50/MP-60, the MP-40 does NOT have per-streaming-service audio inputs (indices 35-42). This may have changed in firmware 5.0.1 which introduced "separate audio input for each streaming type".

## Firmware Details

- **Streaming firmware**: `update-streaming_5.4.1.gpg` (shared with MP-50, MP-60)
- **Streaming platform**: StreamUnlimited StreamSDK (NSDK)
- **Stream type binary**: `nsdkd` (ARM 32-bit, `/usr/bin/nsdkd`)
- **Latest firmware version**: 5.4.1 (April 2026)
