# TDAI-2170 Oracle

Hardware lookup tables for the Lyngdorf TDAI-2170 integrated amplifier.

## Stream Types

**Source: not applicable** — TDAI-2170 has no streaming capability.

The firmware is a 3MB bare-metal DSP update (`.upd` format, latest `ti1_141a.upd` from June 2021). There is no Linux OS, no NSDK streaming platform, no `stream_p` or `nsdkd` binary. Release notes (SW1.15A through SW1.41A) contain no mention of any streaming services.

The library code defines `TDAI2170_STREAM_TYPES` with indices 0-7 but the TDAI-2170 protocol (`TDAI2170_MESSAGES`) has no `Msg.STREAM_TYPE` command and the config has no `has_streaming=True`. This table is vestigial and never queried.

### Recommendation

Remove `TDAI2170_STREAM_TYPES` from `tdai_series.py` or at minimum set it to `{}`.

## Firmware Details

- **Firmware file**: `ti1_141a.upd` (3.04 MB bare-metal update)
- **Update method**: USB stick to rear panel, hold standby button while powering on
- **Latest firmware version**: 1.41a (June 2021, last update)
- **Architecture**: bare-metal DSP (not Linux, no CPIO/UBIFS/tar), ~3MB total
- **Protocol**: older TDAI-2170 protocol (SUBSCRIBE/SUBSCRIBEVOL, no VERB, fixed source/voicing sets)
- **No streaming**: no NSDK, no stream_p, no network streaming services
