# TDAI-3400 Oracle

Hardware lookup tables for the Lyngdorf TDAI-3400 integrated amplifier.

## Stream Types

**Source: firmware-verified** (three functions from `update-tdai3400-3-6-2.gpg`)

- **NSDK string mapping**: `stream_p` binary, stream type mapping function at 0x1882c
- **Display names**: `libtdai.so.0.1.0`, function `get_stream_type_name`, pointer table at file offset 0x2a388
- **Audio input mapping**: `libtdai.so.0.1.0`, function `get_stream_input`, switch table

### Discrepancies with current code

| Index | Code Value | Firmware Value | Status |
|-------|-----------|----------------|--------|
| 7 | Bluetooth | Bluetooth *(name matches but unused)* | **Misleading** — "bluetooth" string exists in binary but stream_p never maps it to index 7; audio input 34 is allocated but unreachable |
| 9 | Unknown | airable | **Wrong** — firmware maps airableRadios/airablePodcasts to index 9 |

### Notes

- Index 7 has "Bluetooth" in the display name table and audio input 34 allocated, but `stream_p` never assigns any NSDK string to index 7. The string "bluetooth" IS in the binary but used by a different subsystem (Bluetooth connectivity, added in firmware 2.0.0), not the stream type mapper. Code listing "Bluetooth" at index 7 is name-correct but functionally wrong — no stream event will ever produce this index.
- Display name for index 5 is "USB File" — matches code. NSDK service name is "Storage".
- Both `airableRadios` and `airablePodcasts` map to index 9.
- No `artistconnection` (PureAudio) string — PureAudio is MP-series only.
- Audio inputs 0 and 11 both map to 255 (no input / passthrough).
- vTuner functionality removed in firmware 3.5.0 but index still exists.
- TIDAL connect added in firmware 2.0.0; STREAMTYPE support added in firmware 2.2.0.
- Qobuz connect added in firmware 3.6.0.

## Audio/Video Inputs

TDAI-3400 uses source list enumeration (SRCLIST?/SRCNAME?) rather than fixed audio/video input indices. The audio input numbers in the stream type table above are internal indices used by `get_stream_input()` to route streaming services to their corresponding source entries.

## Firmware Details

- **Firmware file**: `update-tdai3400-3-6-2.gpg`
- **Streaming platform**: StreamUnlimited StreamSDK (NSDK)
- **Stream type binary**: `stream_p` (ARM 32-bit Thumb-2, `/usr/bin/stream_p`)
- **Stream type library**: `libtdai.so.0.1.0` (ARM 32-bit, `/usr/lib/libtdai.so.0.1.0`)
- **Latest firmware version**: 3.6.2 (April 2026)
