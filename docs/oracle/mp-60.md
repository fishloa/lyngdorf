# MP-60 Oracle

Hardware lookup tables for the Lyngdorf MP-60 multichannel processor.

## Stream Types

**Source: firmware-verified** (disassembled `nsdkd` binary from `update-streaming_5.4.1.gpg`, function `getStreamtypeFromNsdkString` at 0x15840)

All MP series models (MP-40, MP-50, MP-60) share the same streaming firmware and identical stream type mapping.

| Index | Name | NSDK String |
|-------|------|-------------|
| 0 | None | *(default/no match)* |
| 1 | vTuner | VTuner |
| 2 | Spotify | spotify |
| 3 | AirPlay | airplay |
| 4 | UPnP | UPnP |
| 5 | Storage | Storage |
| 6 | Roon Ready | roon |
| 7 | TIDAL | tidal |
| 8 | airable | airableRadios, airablePodcasts |
| 9 | PureAudio | artistconnection |
| 10 | Qobuz | qobuzconnect |

### Notes

- See mp-40.md for full stream type analysis notes.
- No "bluetooth" or "GoogleCast" strings exist in the MP streaming firmware.

## Firmware Details

- **Streaming firmware**: `update-streaming_5.4.1.gpg` (shared with MP-40, MP-50)
- **Streaming platform**: StreamUnlimited StreamSDK (NSDK)
- **Stream type binary**: `nsdkd` (ARM 32-bit, `/usr/bin/nsdkd`)
- **Latest firmware version**: 5.4.1 (April 2026)
