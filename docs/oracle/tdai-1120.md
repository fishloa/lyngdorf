# TDAI-1120 Oracle

Hardware lookup tables for the Lyngdorf TDAI-1120 integrated amplifier.

## Stream Types

**Source: firmware-verified** (three functions from `update-tdai1120_2.6.3.swu`)

- **Audio input mapping**: `libtdai.so.0.1.0`, function `get_stream_input`, switch table at vaddr 0x26274

### Discrepancies with current code

| Index | Code Value | Firmware Value | Status |
|-------|-----------|----------------|--------|
| 1 | vTuner | vTuner *(name matches but unused)* | **Stale** — vTuner removed in firmware 2.5.1; stream_p never assigns index 1 |
| 9 | Unknown | TIDAL | **Wrong** — firmware maps "tidal" to index 9 |
| 10 | Qobuz | airable | **Wrong** — firmware maps airableRadios/airablePodcasts to index 10 |
| 11 | *(missing)* | Qobuz | **Missing** — firmware maps "qobuzconnect" to index 11 |

### Notes

- Display name for index 3 is "Airplay" (lowercase p) — differs from TDAI-3400 "AirPlay" and MP "AirPlay".
- Display name for index 8 is "Googlecast" (lowercase c) — TDAI-1120 specific.
- Display name for index 5 is "USB File" — matches code. NSDK service name is "Storage".
- Bluetooth (7) and GoogleCast (8) are unique to TDAI-1120. Neither appears in MP or TDAI-3400 stream type functions. These extra services push TIDAL/airable/Qobuz up by 2 indices vs TDAI-3400.
- Both `airableRadios` and `airablePodcasts` map to index 10.
- No `artistconnection` (PureAudio) string — PureAudio is MP-series only.
- Audio inputs 0 and 12 both map to input 28 (passthrough/default).
- TIDAL added in firmware 2.0.0. Qobuz added in firmware 2.6.0. GoogleCast updated in firmware 2.1.0.

## Audio/Video Inputs

TDAI-1120 uses source list enumeration (SRCLIST?/SRCNAME?) rather than fixed audio/video input indices. The audio input numbers in the stream type table above are internal indices used by `get_stream_input()` to route streaming services to their corresponding source entries.

## Firmware Details

- **Firmware file**: `update-tdai1120_2.6.3.swu` (SWUpdate CPIO archive)
- **Firmware contents**: UBIFS rootfs (`yocto-nsdk-ip-image-swu-stream810tdai1120.ubifs`), FIT kernel image, U-Boot (i.MX SoC)
- **Hardware platform**: StreamUnlimited Stream810 (`stream810tdai1120`)
- **Streaming platform**: StreamUnlimited StreamSDK (NSDK)
- **Stream type binary**: `stream_p` (ARM 32-bit PIE, `/usr/bin/stream_p`)
- **Stream type library**: `libtdai.so.0.1.0` (ARM 32-bit, `/usr/lib/libtdai.so.0.1.0`)
- **Latest firmware version**: 2.6.3 (March 2026)
