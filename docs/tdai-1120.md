# TDAI-1120 External Control Manual

Integrated amplifier.

## Connection

- Network: TCP port 84 (Bonjour service "slactrl", also reachable at http://TDAI-1120.local)
- Command framing: every command starts with `!` and ends with `<CR>` (0x0D). Status requests end with `?`. Malformed commands are ignored.
- Feedback levels via `!VERB(X)<CR>` (X = 0, 1, or 2): 0 = reply only when queried; 1 = also pushes a status message whenever it changes; 2 = also echoes each command back prefixed with `#` instead of `!`.
- Note: from deep sleep standby, the device may miss the first character(s) sent - send the command a couple of times to be sure.

## Commands

| Command | Reply | Values | Description |
|---|---|---|---|
| `!AUDIOSTATUS ?` | `!AUDIOSTATUS("Audiostring")` | Audiostring describes the current audio input | Requests format information for the current audio input |
| `!BAL ?` | `!BAL(balance)` | L1-L10 = left, 0 = centered, R1-R10 = right | Requests the current balance trim setting |
| `!BAL(balance)` | - | L1-L10 = left, 0 = centered, R1-R10 = right | Sets the balance trim setting |
| `!BASS ?` | `!BASS(n)` | n = -12 to 12 (dB) | Requests the current bass gain trim setting |
| `!BASS(n)` | - | n = -12 to 12 (dB) | Sets the bass gain trim setting |
| `!BASSFREQ ?` | `!BASSFREQ(n)` | n = 20 to 800 (Hz) | Requests the current bass frequency trim setting |
| `!BASSFREQ(n)` | - | n = 20 to 800 (Hz) | Sets the bass frequency trim setting |
| `!DEVICE ?` | `!DEVICE(TDAI-1120)` | - | Requests identifying information |
| `!IPWIFI ?` | `!IPWIFI(xxx.xxx.xxx.xxx)` | Empty string if not connected | Requests the IP of the Wi-Fi interface |
| `!IPWIRED ?` | `!IPWIRED(xxx.xxx.xxx.xxx)` | Empty string if not connected | Requests the IP of the Ethernet interface |
| `!MACWIFI ?` | `!MACWIFI(xx:xx:xx:xx:xx:xx)` | - | Requests the MAC address of the Wi-Fi interface |
| `!MACWIRED ?` | `!MACWIRED(xx:xx:xx:xx:xx:xx)` | - | Requests the MAC address of the Wired interface |
| `!MUTE ?` | `!MUTE(ON)` or `!MUTE(OFF)` | - | Requests the current mute state |
| `!MUTE` | - | - | Toggles the current mute state (same as the mute button on the remote) |
| `!MUTEON` | - | - | Mutes the amplifier |
| `!MUTEOFF` | - | - | Demutes the amplifier |
| `!NEXT` | - | - | Same function as the Next button on the remote control |
| `!OFF` | - | - | Turns the amplifier off |
| `!ON` | - | - | Turns the amplifier on. Note: from Deep Sleep Stand-by, send the command twice |
| `!PLAY` | - | - | Same function as the Play/Pause button on the remote control |
| `!PREV` | - | - | Same function as the Previous command on the remote control |
| `!PWR ?` | `!PWR(ON)` or `!PWR(OFF)` | - | Requests the current power state of the amplifier |
| `!PWR` | - | - | Toggles power state of the amplifier (same as the power button on the remote) |
| `!RP ?` | `!RP(n)` | 0 = Bypass, 1-8 = Focus positions 1-8, 9 = Global | Requests the currently selected RoomPerfect position |
| `!RP(n)` | - | 0 = Bypass, 1-8 = Focus positions 1-8, 9 = Global | Selects a new RoomPerfect position (if available) |
| `!RPDN` | - | - | Selects the previous RoomPerfect position (down-arrow on remote) |
| `!RPUP` | - | - | Selects the next RoomPerfect position (up-arrow on remote) |
| `!RPLIST ?` | `!RPCOUNT(N)` then `!RPNAME(a,"Name")` per position | N = total positions; a, b, etc. are position numbers; Name is the position's name. One line per available position | Requests the index and name of each available RoomPerfect position |
| `!RPNAME ?` | `!RPNAME(n,"Name")` | n = currently selected position | Requests the name of the currently selected RoomPerfect position |
| `!RPNAME(n) ?` | `!RPNAME(n,"Name")` | Name is empty if position n does not exist | Requests the name of RoomPerfect position n |
| `!SRC ?` | `!SRC(n)` | n = index of currently selected source | Requests the currently selected source |
| `!SRCLIST ?` | `!SRCCOUNT(N)` then `!SRCNAME(a,"Name")` per source | N = total sources; a, b, etc. are source numbers; Name is the source's name. One line per enabled source | Requests a list of all available and enabled sources |
| `!SRC(n)` | - | n = any index from the list returned by `!SRCLIST ?` | Selects source n |
| `!SRCDN` | - | - | Selects the previous source (same as "SRC -" on the remote) |
| `!SRCUP` | - | - | Selects the next source (same as "SRC +" on the remote) |
| `!SRCNAME ?` | `!SRCNAME(n,"Name")` | n = currently selected source | Requests the name of the currently selected source |
| `!SRCNAME(n) ?` | `!SRCNAME(n,"Name")` | Name is empty if source n does not exist or is disabled | Requests the name of source n |
| `!STREAMTYPE ?` | `!STREAMTYPE(n)` | 0=none, 1=vTuner, 2=Spotify, 3=AirPlay, 4=uPnP, 5=USB File, 6=Roon Ready, 7=Bluetooth, 8=GoogleCast, 9=Unknown | Requests the stream type currently being played |
| `!SWVER ?` | `!VER(Verstring)` | Verstring describes the SW version | Requests the current software version information |
| `!TREBLE ?` | `!TREBLE(n)` | n = -12 to 12 (dB) | Requests the current treble gain trim setting |
| `!TREBLE(n)` | - | n = -12 to 12 (dB) | Sets the treble gain trim setting |
| `!TREBLEFREQ ?` | `!TREBLEFREQ(n)` | n = 1500 to 16000 (Hz) | Requests the current treble frequency trim setting |
| `!TREBLEFREQ(n)` | - | n = 1500 to 16000 (Hz) | Sets the treble frequency trim setting |
| `!VERB ?` | `!VERB(n)` | n = current verbosity setting (0, 1, or 2) | Requests the current verbosity setting |
| `!VERB(n)` | - | n = new verbosity level (0, 1, or 2) | Sets a new verbosity level for the interface |
| `!VOI ?` | `!VOI(n)` | n = currently selected voicing | Requests the currently selected voicing |
| `!VOI(n)` | - | n = any value from the list returned by `!VOILIST ?` | Selects a new voicing |
| `!VOIDN` | - | - | Selects the previous voicing (left arrow on remote) |
| `!VOIUP` | - | - | Selects the next voicing (right arrow on remote) |
| `!VOILIST ?` | `!VOICOUNT(N)` then `!VOINAME(a,"Name")` per voicing | N = total voicings; a, b, etc. are voicing numbers; Name is the voicing's name. One line per voicing | Requests a list of available voicings |
| `!VOINAME ?` | `!VOINAME(n,"Name")` | n = currently selected voicing; Name empty if it does not exist | Requests the name of the currently selected voicing |
| `!VOINAME(n) ?` | `!VOINAME(n,"Name")` | Name is the name of voicing n | Requests the name of voicing n |
| `!VOL ?` | `!VOL(n)` | n = -999 to 120 (steps of 0.1dB) | Requests the current volume |
| `!VOL(n)` | - | n = -999 to 120 (steps of 0.1dB) | Sets the current volume to a new value |
| `!VOLCH(n)` | - | n = -999 to 999 (steps of 0.1dB) | Changes the volume by the requested amount |
| `!VOLDN` | - | - | Volume down (by 0.5dB) |
| `!VOLUP` | - | - | Volume up (by 0.5dB) |
