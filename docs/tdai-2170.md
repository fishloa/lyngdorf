# TDAI-2170 External Control Manual

Integrated amplifier.

## Connection

- Serial: 8 data bits, no parity, 1 stop bit, 115200 baud.
- Command framing: commands/requests start with `!`. Commands end with `<CR><LF>` (a single `<CR>` is also commonly accepted). Requests end with `?` then `<CR><LF>`. Replies are formatted as the request with reply values as parameters. Malformed commands/requests are ignored.
- Push notifications: this device has no feedback-level setting (no VERB command) - instead, send `!SUBSCRIBE<CR><LF>` to receive a status push whenever input/RoomPerfect-position/voicing/power/mute changes, and `!SUBSCRIBEVOL<CR><LF>` separately to receive volume-change pushes. `!UNSUBSCRIBE`/`!UNSUBSCRIBEVOL` turn these off. A subscribed status push is formatted like a reply but followed by `!` before `<CR><LF>` to mark it as unsolicited.

## Commands

| Command | Reply | Values | Description |
|---|---|---|---|
| `!VER?` | `!VER(Verstring)` | Verstring is a string, e.g. `1.23a` | Requests the SW version. |
| `!DEVICE?` | `!DEVICE(TDAI-2170)` | - | Requests the device type. |
| `!PWR?` | `!PWR(ON)` or `!PWR(OFF)` | - | Requests the current power state. |
| `!PWR` | | | Toggles power on the amplifier. Same as the standby button on the front. |
| `!ON` | | | Turns the amplifier on. |
| `!OFF` | | | Turns the amplifier off. |
| `!VOL?` | `!VOL(v)` | -999 to 120 (0.1dB steps) | Requests the current volume. |
| `!VOL(n)` | | -999 to 120 (0.1dB steps) | Sets the volume to n. Handled in 0.1dB steps. |
| `!VOLUP` | | | Increases the volume 1 step (0.5dB). |
| `!VOLDN` | | | Decreases the volume 1 step (0.5dB). |
| `!VOLCH(d)` | | delta, 0.1dB steps | Changes the volume by delta d, e.g. `!VOLCH(-32)` turns down 3.2dB. |
| `!MUTE?` | `!MUTE(ON)` or `!MUTE(OFF)` | - | Requests the mute status. |
| `!MUTE` | | | Toggles mute. |
| `!MUTEON` | | | Mutes the amplifier. |
| `!MUTEOFF` | | | Demutes the amplifier. |
| `!SRC?` | `!SRC(n)` | n = source index, see Input Source Numbering | Requests the currently selected input source. |
| `!SRC(n)` | | n = source index | Selects source n, if enabled. |
| `!SRCALL(n)` | | n = source index | Selects source n even if it is not enabled. |
| `!SRCUP` | | | Selects the next enabled input source. |
| `!SRCDN` | | | Selects the previous enabled input source. |
| `!SRCNAME(n)?` | `!SRCNAME(n,Name)` | Name = source name string | Requests the name of input source n. |
| `!SRCENABLED?` | `!SRCENABLED(b)` | b = bitmask, bit0 (LSB, rightmost) = source 0, etc. | Requests which input sources are enabled by the user. |
| `!VOI?` | `!VOI(n)` | n = voicing index, see Voicing Numbering | Requests the currently selected voicing. |
| `!VOI(n)` | | n = voicing index | Selects voicing n. |
| `!VOIUP` | | | Selects the next voicing. |
| `!VOIDN` | | | Selects the previous voicing. |
| `!VOINAME(n)?` | `!VOINAME(n,Name)` | Name = voicing name string | Requests the name of voicing n. |
| `!VOIENABLED?` | `!VOIENABLED(b)` | b = 16-bit bitmask, bit0 (LSB) = Voicing 0 (Neutral, always enabled), bit1 = Voicing 1, etc. | Requests which voicings are enabled. |
| `!RP?` | `!RP(n)` | n: 0 = Bypass, 1-8 = Focus positions, 9 = Global | Requests the currently selected RoomPerfect position. |
| `!RPFOC(n)` | | n = 1-8 | Selects RoomPerfect focus position n. |
| `!RPUP` | | | Selects the next RoomPerfect position. |
| `!RPDN` | | | Selects the previous RoomPerfect position. |
| `!RPBP` | | | Selects the RoomPerfect Bypass position, if enabled. |
| `!RPGLOB` | | | Selects the RoomPerfect Global position. |
| `!RPSTATUS?` | `!RPSTATUS(b)` | b = 8-bit bitmask, bit0 (LSB) = Focus1 present, bit1 = Focus2, etc. | Requests which RoomPerfect focus positions are present. If any focus position is present, Global is also available. |
| `!SUBSCRIBE` | | | Activates subscription mode: pushes a status whenever input, RoomPerfect position, voicing, power, or mute changes. Stays active until power is removed or `!UNSUBSCRIBE` is sent. |
| `!UNSUBSCRIBE` | | | Deactivates subscription mode. |
| `!SUBSCRIBEVOL` | | | Activates volume-change subscription mode. Stays active until power is removed or `!UNSUBSCRIBEVOL` is sent. |
| `!UNSUBSCRIBEVOL` | | | Deactivates volume-change subscription mode. |
